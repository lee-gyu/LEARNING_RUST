# kvconf

`키 = 값` 줄로 된 작은 설정 파일을 읽는 라이브러리입니다. 의존성이 없고, 형식을 일부러 작게 잡았습니다.

- 지원하는 것: 한 줄에 `키 = 값` 하나, `#`으로 시작하는 주석 줄, 파일에 적힌 키 순서, 잘못된 줄의 번호를 알려 주는 에러
- 지원하지 않는 것: 섹션, 따옴표, 줄 끝 주석, 여러 줄에 걸친 값. 이런 형식이 필요하면 TOML 파서를 고르세요.

사용법과 API 설명은 크레이트 문서(`cargo doc --open`, 게시한 크레이트라면 docs.rs)에 있고,
실행해 볼 수 있는 사용 예는 `examples/startup.rs`에 있습니다.
